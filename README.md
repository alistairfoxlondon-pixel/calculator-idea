# calculator-idea

A small, fast, keyboard-first calculator.

## Status

Design phase — no implementation yet. The arithmetic rules, edge cases, and
planned feature set are written up in [docs/IDEA.md](docs/IDEA.md).

## Documentation

- [Calculator Idea](docs/IDEA.md) — goals, feature priorities, behavior notes,
  accessibility requirements, and roadmap.

## Contributing

Open an issue for ideas or bugs. Pull requests are welcome — keep changes small,
describe the behavior being changed, and add a test when fixing a bug.
